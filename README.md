# 📌 FastAPI TODO — Backend API

Проект на **FastAPI**, реализующий функционал управления задачами (To-Do) с поддержкой пользователей, JWT-аутентификации и базой данных.

---

## 📋 Возможности

- Регистрация и авторизация пользователей  
- JWT-токены (логин, защита приватных роутов)  
- CRUD-операции с задачами (создать, получить, изменить, удалить)  
- SQLite (по умолчанию) или возможность подключить другую БД  
- Pydantic-схемы + SQLAlchemy-модели  
- Готовая структура проекта  
- Поддержка тестов через `pytest`

# ⚙ Настройка проекта

## 1️⃣ Клонирование репозитория

```
git clone https://github.com/PhoenixDK404/fastapi_todo.git
cd fastapi_todo
```

## 2️⃣ Создание файла .env

Перед запуском приложения создайте файл `.env` на основе `.env.example`:

```cmd
copy .env.example .env
```

После создания .env установите свои значения:

DATABASE_URL — путь к базе данных.

SECRET_KEY — ваш секретный ключ для JWT.

ALGORITHM — алгоритм для JWT (HS256 по умолчанию).

ACCESS_TOKEN_EXPIRE_MINUTES — время жизни токена в минутах.

## 3️⃣ Установка зависимостей
Через Poetry:
```
poetry install
poetry shell
```

## 🚀 Запуск приложения
```
uvicorn app.main:app --reload
```

Открыть:

*Swagger UI: http://localhost:8000/docs

*ReDoc: http://localhost:8000/redoc

## 🧪 Тестирование
```
pytest -v
```

## 🐳 Запуск через Docker
Построить образ:
```
docker build -t fastapi-todo .
```
Запустить контейнер:
```
docker run -d -p 8000:8000 --name fastapi-todo-app fastapi-todo
```


## ⚙ Проверка качества кода

В проекте используется Flake8 для проверки качества кода: стиля, форматирования и потенциальных ошибок.

Установка Flake8 и плагинов(для проверки docstrings)
```
pip install flake8 flake8-docstrings
```

Запускайте следующую команду из корневого каталога проекта, чтобы проверить весь код:
```
flake8 .
```

Проверить конкретный файл:
```
flake8 app/main.py
```

Если проверка найдет ошибки, появится список, который нужно исправить.

## 📌 API Методы FastAPI

Ниже перечислены основные эндпоинты приложения.

### 🔑 Аутентификация

| Метод | Путь | Описание |
|-------|------|----------|
| POST  | `/token` | Получение JWT токена по username и password |
| GET   | `/users/me` | Получение информации о текущем аутентифицированном пользователе |

### 👤 Пользователи (Users)

| Метод | Путь | Описание |
|-------|------|----------|
| POST  | `/users/` | Создать нового пользователя (регистрация) |
| GET   | `/users/` | Получить список всех пользователей |
| GET   | `/users/{id}` | Получить данные пользователя по ID |
| PUT   | `/users/{id}` | Обновить данные пользователя (только для владельца) |
| DELETE| `/users/{id}` | Удалить пользователя (только для владельца) |

### 📝 Задачи (Tasks)

| Метод | Путь | Описание |
|-------|------|----------|
| POST  | `/tasks/` | Создать новую задачу для текущего пользователя |
| GET   | `/tasks/` | Получить список всех задач текущего пользователя |
| GET   | `/tasks/{id}` | Получить конкретную задачу по ID (только владелец) |
| PUT   | `/tasks/{id}` | Обновить задачу (только владелец) |
| DELETE| `/tasks/{id}` | Удалить задачу (только владелец) |
