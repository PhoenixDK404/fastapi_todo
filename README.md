**FastAPI Backend: Сервис управления пользователями и задачами**


Этот проект представляет собой полнофункциональный backend-сервис, разработанный на базе фреймворка FastAPI. Сервис обеспечивает полное управление пользователей и их задач с надежной системой аутентификации.

**Основные Возможности:**

Аутентификация (JWT): Безопасный вход в систему с использованием JSON Web Tokens.

Управление Пользователями (CRUD): Создание, чтение, обновление и удаление учетных записей.

Управление Задачами (CRUD): Полный контроль над задачами, привязанными к конкретному пользователю.

Хэширование Паролей: Используется надежный алгоритм для защиты учетных данных.

**Настройка и Запуск Локально**

Для управления зависимостями и изоляции окружения используется Poetry.

**1. Требования**

Убедитесь, что установлены:

Python 3.11+

Poetry

**2. Установка Зависимостей**

Перейдите в корневой каталог проекта и установите все необходимые пакеты, включая пакеты для разработки и тестирования:
```
cd проект

poetry install
```

**3. Активация Виртуального Окружения**
```
poetry shell
```

**4. Запуск Сервера**

Запустите FastAPI-приложение с помощью Uvicorn в режиме отслеживания изменений:
```
poetry run uvicorn app.main:app --reload --host 0.0.0.0 --port 8005
```

Сервис доступен: http://localhost:8005

**Тестирование**

Проект включает набор тестов с использованием фреймворка Pytest для проверки ключевого функционала: создания пользователей, аутентификации и работы с задачами.

**Запуск Тестов**

Внутри активного Poetry-окружения выполните:
```
poetry run pytest
```


**Контейнеризация (Docker): **

Используйте Docker для создания переносимого и стабильного образа приложения.

**1. Сборка Образа**
```
docker build -t fastapi-task-manager:latest .
```

**2. Запуск Контейнера**
```
docker run -d -p 8005:8005 --name task-manager-app fastapi-task-manager:latest
```

Теперь API доступен по адресу: http://localhost:8005.
